# Contributing

Corrections and improvements are welcome.

**Most useful contributions:**
- A prompt that produced a wrong or fabricated result, with the input you used
- Outdated identifiers: event IDs, GUIDs, framework versions, vendor defaults
- A failure mode a prompt should guard against but doesn't

**Please don't submit:** offensive tooling, exploit code, or prompts designed to bypass security controls. This is a defensive library.

Open an issue with the prompt name, what you expected, and what you got.
