## A note on data handling — read this first

**Be careful what you paste into a third-party LLM.** Public and cloud models may retain or train on what you submit.

- Don't paste live secrets, credentials, API keys, PII, or anything classified/regulated into a public model.
- Sanitise and defang where you can. Redact internal hostnames, user identities and sensitive IPs unless you run an approved enterprise or self-hosted model with the right data agreements.
- Check your organisation's AI-use policy before sending operational data anywhere.

For the most sensitive work, run these prompts against a local or enterprise-governed model.
